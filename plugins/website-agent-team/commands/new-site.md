Запусти мастер создания сайта из навыка `website-team`.

- Задавай по одному вопросу за раз, с вариантами-кнопками (через инструмент вопросов с вариантами, если он доступен) и вариантом «Не знаю — выбери сам».
- Показывай прогресс: `Шаг N из 8 — <название>`.
- На шагах «Дизайн», «Фон» и при выборе секций/кнопок дополнительно предлагай готовые секции, фоны и кнопки OriginKit по навыку `originkit-ui`, указывая slug и ссылку на превью.
- Для анимированных фонов используй `motion-background-studio`, для реализации — `website-engineering`.
- Не начинай писать код до финального подтверждения.

Пожелания пользователя (если есть): $ARGUMENTS
